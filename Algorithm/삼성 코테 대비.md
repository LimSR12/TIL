## 2. 핵심 알고리즘 & 구현 패턴

### 2.1 BFS (너비 우선 탐색) ⭐⭐⭐

> **삼성 최빈출**. 격자 탐색, 최단 거리, 영역 카운트 등에 사용.

```cpp
int dx[] = {-1, 1, 0, 0};  // 상하좌우
int dy[] = {0, 0, -1, 1};
bool visited[101][101];
int board[101][101];
int N, M;

void bfs(int sx, int sy) {
    queue<pair<int,int>> q;
    q.push({sx, sy});
    visited[sx][sy] = true;

    while (!q.empty()) {
        auto [x, y] = q.front();  // C++17 구조적 바인딩
        q.pop();

        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d];
            int ny = y + dy[d];

            // 범위 체크 + 방문 체크 + 조건 체크
            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
            if (visited[nx][ny]) continue;
            if (board[nx][ny] == 0) continue; // 벽 등 조건

            visited[nx][ny] = true;
            q.push({nx, ny});
        }
    }
}
```

**BFS 최단거리 변형:**

```cpp
int dist[101][101]; // -1로 초기화

int bfs(int sx, int sy, int ex, int ey) {
    memset(dist, -1, sizeof(dist));
    queue<pair<int,int>> q;
    q.push({sx, sy});
    dist[sx][sy] = 0;

    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();

        if (x == ex && y == ey) return dist[x][y];

        for (int d = 0; d < 4; d++) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
            if (dist[nx][ny] != -1) continue;
            if (board[nx][ny] == 0) continue;

            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    return -1; // 도달 불가
}
```

### 2.2 DFS (깊이 우선 탐색) + 백트래킹 ⭐⭐⭐

> **순열/조합 생성, 모든 경우 탐색**에 필수.

```cpp
// 기본 DFS (재귀)
void dfs(int x, int y) {
    visited[x][y] = true;

    for (int d = 0; d < 4; d++) {
        int nx = x + dx[d], ny = y + dy[d];
        if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
        if (visited[nx][ny] || board[nx][ny] == 0) continue;
        dfs(nx, ny);
    }
}
```

**백트래킹 (조합/순열 생성):**

```cpp
// N개 중 M개 고르기 (조합)
int selected[10];
bool used[10];

void combination(int start, int depth, int n, int m) {
    if (depth == m) {
        // selected[0..m-1] 에 선택된 값
        // → 여기서 시뮬레이션 등 수행
        return;
    }
    for (int i = start; i < n; i++) {
        selected[depth] = i;
        combination(i + 1, depth + 1, n, m);
    }
}

// 순열
void permutation(int depth, int n, int m) {
    if (depth == m) {
        // 처리
        return;
    }
    for (int i = 0; i < n; i++) {
        if (used[i]) continue;
        used[i] = true;
        selected[depth] = i;
        permutation(depth + 1, n, m);
        used[i] = false;  // 백트래킹 핵심: 복원
    }
}
```

adj[u].push_back(v);
adj[v].push_back(u); // 무방향

// 트리 부모 찾기 (BFS)

void findParent(int root) {
    queue<int> q;
    q.push(root);
    visited[root] = true;
    while (!q.empty()) {
        int cur = q.front(); q.pop();
        for (int next : adj[cur]) {
            if (visited[next]) continue;
            visited[next] = true;
            parent[next] = cur;
            q.push(next);
        }
    }

### 2.6 다익스트라 (최단경로)

```cpp
typedef pair<int,int> pii;
vector<pii> adj[10001]; // {비용, 다음노드}
int dist[10001];

void dijkstra(int start) {
    fill(dist, dist + 10001, INT_MAX);
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    dist[start] = 0;
    pq.push({0, start});

    while (!pq.empty()) {
        auto [cost, cur] = pq.top(); pq.pop();

        if (cost > dist[cur]) continue; // 이미 더 짧은 경로 존재

        for (auto [w, next] : adj[cur]) {
            if (dist[cur] + w < dist[next]) {
                dist[next] = dist[cur] + w;
                pq.push({dist[next], next});
            }
        }
    }
}
```

### 2.7 유니온 파인드 (Disjoint Set)

```cpp
int parent[10001];
int rnk[10001]; // rank

void init(int n) {
    for (int i = 0; i <= n; i++) { parent[i] = i; rnk[i] = 0; }
}

int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]); // 경로 압축
    return parent[x];
}

void unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return;
    if (rnk[a] < rnk[b]) swap(a, b);
    parent[b] = a;
    if (rnk[a] == rnk[b]) rnk[a]++;
}
```

### 3.2 BFS + 조건부 탐색

**변형 패턴:**

- 3차원 visited: `visited[x][y][상태]`
- 벽 부수기: `visited[x][y][부순횟수]`
- 열쇠 들고 BFS: `visited[x][y][열쇠비트마스크]`

```cpp
// 예: 벽을 최대 K번 부수며 최단거리
bool visited[101][101][11]; // [행][열][부순횟수]
struct State { int x, y, broken, dist; };

int bfs() {
    queue<State> q;
    q.push({0, 0, 0, 1});
    visited[0][0][0] = true;

    while (!q.empty()) {
        auto [x, y, broken, d] = q.front(); q.pop();
        if (x == N-1 && y == M-1) return d;

        for (int dir = 0; dir < 4; dir++) {
            int nx = x + dx[dir], ny = y + dy[dir];
            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;

            // 빈 칸
            if (board[nx][ny] == 0 && !visited[nx][ny][broken]) {
                visited[nx][ny][broken] = true;
                q.push({nx, ny, broken, d + 1});
            }
            // 벽 부수기
            if (board[nx][ny] == 1 && broken < K && !visited[nx][ny][broken + 1]) {
                visited[nx][ny][broken + 1] = true;
                q.push({nx, ny, broken + 1, d + 1});
            }
        }
    }
    return -1;
}
```

## 4. 디버깅 & 실전 팁

### 4.1 흔한 실수 체크리스트

- [ ] **배열 크기**: N ≤ 100이면 배열은 `[101]` 이상으로 선언
- [ ] **0-indexed vs 1-indexed**: 문제가 1부터 시작하면 배열도 1부터 사용
- [ ] **int 오버플로우**: 곱셈 결과가 2×10⁹ 넘으면 `long long`
- [ ] **memset 오용**: 0, -1 외의 값은 `fill` 사용
- [ ] **visited 초기화**: 테스트케이스 여러 개일 때 반복마다 초기화
- [ ] **방향 배열 순서**: dx/dy 순서가 문제 조건(상하좌우 등)과 일치하는지
- [ ] **동시 처리**: 원본 배열을 순회하면서 원본을 수정하고 있지는 않은지
- [ ] **경계 체크**: `nx >= 0` 빠뜨리지 않았는지
- [ ] **return 누락**: 함수에서 값을 반환하지 않는 경로가 없는지

### 4.2 시간복잡도 가이드

| N 범위       | 허용 복잡도 | 대표 알고리즘        |
| ------------ | ----------- | -------------------- |
| ≤ 10         | O(N!)       | 순열 전탐색          |
| ≤ 20         | O(2^N)      | 비트마스크, 부분집합 |
| ≤ 100        | O(N³)       | 플로이드, 3중 루프   |
| ≤ 1,000      | O(N²)       | 2중 루프, 브루트포스 |
| ≤ 100,000    | O(N log N)  | 정렬, 이분탐색       |
| ≤ 10,000,000 | O(N)        | 선형 탐색, 투 포인터 |

> 삼성 기준: 보통 2초 제한, 약 **1~2억 연산**까지 가능

## 5. 시험 직전 최종 체크

1. **`#include <bits/stdc++.h>`** 와 **`ios::sync_with_stdio(false); cin.tie(NULL);`** 외우기
2. **dx, dy 배열** 바로 적을 수 있도록 연습
3. **BFS 틀** 3분 안에 작성 가능하도록 연습
4. **백트래킹(조합)** 틀 바로 작성 가능하도록 연습
5. 문제를 끝까지 읽고, **좌표계/인덱싱/동시처리 여부** 먼저 확인
6. 코너 케이스: N=1, 빈 입력, 최대값 테스트
7. 삼성은 보통 **2문제 / 3~4시간** → 문제당 약 1.5~2시간 배분
8. 막히면 **가장 단순한 풀이(완전탐색)**부터 시도 → 최적화는 나중에
