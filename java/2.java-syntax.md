# Java 기본 문법

## 1) Java 프로그램의 구조

Java 에서 실행되는 모든 코드는 클래스 내부에 있어야 한다.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

Java는 case-sensitive한 언어이다. `MyClass` 와 `myclass` 는 다르게 인식된다!

## 2) 클래스 이름과 파일 이름 규칙

클래스 이름은 첫 글자를 대문자로 쓰는 것이 관례이다.
Java 파일명과 클래스 명은 일치해야 한다. 만약 클래스명이 `Main` 이라면 파일명도 `Main.java` 여야 한다.

## 3) main() 메서드

모든 Java 프로그램은 항상 이 main() 메서드부터 실행이 시작된다.
이 메서드 안에 적은 코드가 프로그램의 실행 내용이다.
